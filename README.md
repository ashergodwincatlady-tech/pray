# PYN: Google accounts and community

Read SETUP.md first. Fill firebase-config.js, enable Google in Firebase Authentication, authorize your deployment domain, create Firestore, publish firestore.rules, and redeploy all app files.

The app includes Google sign-in, first-time username and age setup, a real same-age-group member list, shared realtime chat, local blocking, reports, deleting your own messages, and the expanded Python course. Chat and member discovery require your connected Firebase project. Without configuration, the lesson preview works and the app explains that Google sign-in is not connected.

This package has not been deployed. Live Google authentication and Firestore behavior cannot be verified until your project is configured. Age groups are based on entered ages, not independent verification. Progress and personal projects remain local per account.
